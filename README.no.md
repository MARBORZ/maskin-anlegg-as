# maskin-anlegg-as

[English](README.md) · Norsk

Landingsside for MK Maskin & Anlegg AS – norsk firma som tar vare på eiendom for borettslag, sameier og næring. Kundeprosjekt.

Next.js, Motion for animasjoner, Embla for karuseller. Kontaktskjemaet sender e-post via Resend fra `api/contact`. Hostet på Vercel.

## Kjør

```bash
npm install
npm run dev
```

Skjemaet trenger `RESEND_API_KEY` i `.env.local`.
